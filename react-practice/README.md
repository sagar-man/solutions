# react-practice

Reference implementation + prep kit for a 45-minute React/TypeScript pairing exercise:
a client-side router, state that persists across navigation, and a local JSON file
rendered as a list.

**Start with [PRACTICE.md](./PRACTICE.md)** — setup commands, the three concepts in
minimal form, a minute-by-minute plan for the exercise, timed drills, and mock specs.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b + vite build
```

Stack: Vite, React 19, TypeScript, React Router 7. No other dependencies.
